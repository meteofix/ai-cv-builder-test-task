# PDF fixtures

How each file was made, so it can be made again.

- `encrypted.pdf` — a one-page PDF with the text "Encrypted CV", protected with the user password `secret` (Standard security handler, revision 2, RC4 40-bit). Generated by `node apps/api/test/cvs/fixtures/make-encrypted-pdf.mjs`; no PDF tool in the dependency set can encrypt. Without the password `unpdf` throws a `PasswordException`; with it the text is "Encrypted CV".

Other fixtures of `docs/specs/cvs.md` (a text PDF, an image-only PDF, eleven pages) are printed by Chromium from HTML inside the tests, or added here with a line on how they were made.
