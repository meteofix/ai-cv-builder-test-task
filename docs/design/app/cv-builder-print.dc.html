CV Builder — interface reference

Еталон для перенесення в React + Tailwind 4. Токени й компоненти — у cv-builder.css (токени на початку файлу), стиль аркуша — у cv-template.css (те саме, що renderCvShell). Кожна рамка — окремий контейнер: @container app у макеті замінює звичайні брейкпоінти.

1c

Component states

Статус автозбереження (role="status", aria-live="polite") і «Download PDF», яка неактивна, поки збереження не завершене або йде AI-задача. Праворуч — розгорнута панель «Not in your CV».

2a — липка панель секцій угорі (горизонтально прокручується всередині себе, сторінка — ні). Картки досвіду й освіти — згорнуті <details>. Внизу липка панель: статус збереження, «Preview» (відкриває <dialog>) і «Download PDF».

2b

Preview dialog

<dialog> через showModal(), на весь екран; аркуш на всю ширину. Закриття — <form method="dialog"> або Esc, фокус повертається на «Preview».
