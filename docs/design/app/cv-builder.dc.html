CV Builder — interface reference

Еталон для перенесення в React + Tailwind 4. Токени й компоненти — у cv-builder.css (токени на початку файлу), стиль аркуша — у cv-template.css (те саме, що renderCvShell). Кожна рамка — окремий контейнер: @container app у макеті замінює звичайні брейкпоінти.

1a

Editor · desktop 1280 · default

Форма ліворуч, превʼю праворуч (sticky). Превʼю в застосунку — <iframe sandbox="allow-same-origin">, аркуш 794 px масштабується під ширину колонки. «Add phone» лише фокусує поле Phone. «Not in your CV» згорнута за замовчуванням — розгорнутий вигляд у 1c.

Editor · phone 360

Editor · phone · Preview dialog

<dialog> через showModal(), на весь екран; аркуш на всю ширину. Закриття — <form method="dialog"> або Esc, фокус повертається на «Preview». Кнопка «Preview» у 2a відкриває справжній діалог.
